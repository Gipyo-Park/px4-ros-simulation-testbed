# HIL and Indoor Flight Experiments

<img src="../assets/images/hil-indoor-testbed.png" width="100%" alt="HIL and indoor flight testbed">

## Experimental Setup

- PX4/Pixhawk-based flight hardware
- Ground-control station and telemetry monitoring
- Thrust-measurement system
- Motion-capture-based indoor positioning
- Indoor flight-test area

## Demonstration Scope

This documentation records the experimental setup and representative flight
demonstrations. Quantitative performance results are kept separate from this
overview.
