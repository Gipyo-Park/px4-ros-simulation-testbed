## GIF Filenames

Use these names when the converted files are ready:

```text
assets/demos/
├── sils-automation-demo.gif
├── motor-fault-demo.gif
├── wind-disturbance-demo.gif
├── hil-setup-demo.gif
└── indoor-flight-demo.gif
```

Recommended export settings:

- 6–10 seconds per preview
- 720p or smaller
- 10–15 frames per second
- Under 10 MB when possible

The root README currently contains no links to missing GIF files. Add each GIF
only after the final file exists so that the published page never shows a
broken media element.
